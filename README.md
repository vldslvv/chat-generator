## Offline delivery demo

Watch Alice and Bob exchange messages, go offline, queue messages locally, and
reconnect to deliver them. Install Python 3.12 or later, `uv`, Cargo, `make`, and
`tmux`, then run this from the repository root in a terminal outside tmux:

```sh
make demo-offline-delivery
```

The command syncs the Python environments and builds the Rust client automatically.
It opens **Server**, **Alice**, **Bob**, and **Walkthrough** panes together in one
tmux window. Steps run automatically with a five-second delay before each action;
the Walkthrough explains what is happening. Press **q** to exit. The completed
transcript stays visible until you exit, then the demo cleans up its processes
and tmux session.

Run the same scenario headlessly with both client language assignments:

```sh
make test-offline-delivery
```

See the [runner guide](tools/offline_delivery/README.md) for configuration when
using a different or regenerated implementation.
