# Project memory

Apply during ordinary planning, implementation and memory handoffs.

- For ordinary work, read `<project-root>/.agentic-workflow/memory/index.md`, then only relevant `entries/*.md`.
- Treat a missing index as no saved notes.
- Follow current requirements and repository facts over conflicting memory.
- Check advice that may be outdated.
- Do not search unrelated tasks or conversations.
- Save only useful, source-backed lessons when work finishes or is blocked.
- Merge duplicate notes and correct outdated advice.
- Use ordinary Markdown without requiring metadata.
- Write short hints that help later workers find relevant notes.
- Leave out transcripts, progress logs, guesses, secrets and copied configuration.
- Pass relevant note paths to later workers doing ordinary work.
- As Supervisor, pass paths without reading detailed notes.
- Do not read memory or copies of it as a reviewer, validator or reconstruction worker.
